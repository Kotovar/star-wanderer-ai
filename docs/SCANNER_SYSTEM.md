# 📡 Система Сканера

## Обзор

Сканер — это ключевая система для обнаружения объектов в космосе. Без сканера игрок не может обнаруживать врагов, аномалии, дружественные корабли и другие опасные объекты до входа в них.

---

## 📋 Компоненты системы

### 1. Модуль Сканера

**Модуль `scanner`** — основной компонент для сканирования.

| Уровень  | Потребление | Диапазон | Здоровье | Защита |
|---------|-------------|----------|----------|--------|
| 1 | -2 | 3 | 100 | 1 |
| 2 | -4 | 5 | 120 | 2 |
| 3 | -6 | 8 | 140 | 3 |
| 4 | -9 | 15 | 200 | 4 |

**Цвет:** Голубой (`#00d4ff`)

**Важно:** Сканер должен быть **активен** (здоровье > 0, не отключён вручную) для работы.

Технологии `scan_range` прибавляются к эффективной дальности динамически. Поле `scanRange` хранит только аппаратную дальность (3 / 5 / 8 / 15), поэтому технологии не меняют тир МК-1/МК-2/МК-3. В карточке сканера прибавка показывается отдельно: `3 (+9 технологий) = 12`.

### 2. Артефакты

#### 🔮 Квантовый сканер (Quantum Scan)
- **Эффект:** +3 к диапазону сканирования (усиливается общими множителями артефактов)
- **Требование:** Должен быть установлен хотя бы один модуль сканера
- **Тип:** `quantum_scan`

#### 👁️ Глаз Сингулярности (All Seeing / Eye of Singularity)
- **Эффект:** Заменяет сканер, даёт диапазон 8 (эквивалент сканера 3 уровня)
- **Особенность:** Работает без модуля сканера
- **Тип:** `all_seeing`

### 3. Расовые бонусы

#### Кристаллический резонанс (Crystalline Resonance)
- **Эффект:** +15% к эффектам артефактов
- **Применение:** Увеличивает бонус от `quantum_scan`
- **Расовая принадлежность:** Требуется член экипажа с этой чертой

## 🎯 Пороги видимости объектов

Сканер раскрывает тип и параметры объектов в зависимости от своего **эффективного диапазона**:

| Диапазон | Типы объектов |
|----------|---------------|
| **≥ 3** | Дружественные корабли (friendly_ship), Аномалии 1 тира, Космические существа 1 тира, **Тип станции** |
| **≥ 5** | Аномалии 2 тира, Штормы (storm), Враги и космические существа 2 тира |
| **≥ 8** | Враги и космические существа 3 тира, Боссы (boss), Аномалии 3 тира |
| **≥ 15** | Аномалии 4 тира, **Раскрытие типа сигнала бедствия** |

На карте галактики рядом с текущей дальностью показана понятная подсказка о боссах: без сканера — «для обнаружения боссов нужна дальность 8», с дальностью 6 — «до обнаружения боссов: +2», а с дальностью 8 и выше — «боссы обнаруживаются».

На карте сектора показывается эффективная дальность, а не тир модуля. Поэтому МК-1 с базовой дальностью 3 и технологической прибавкой +9 отображается как «Дальность сканирования: 12», но остаётся МК-1.

### Всегда видимые объекты
Следующие объекты видны **без сканера** (иконка и название на карте):
- 🏠 Станции (station) — тип раскрывается при scanRange ≥ 3
- 🪐 Планеты (planet) — детали раскрываются постепенно (3/5/8)
- ☄️ Пояса астероидов (asteroid_belt) — ресурсы при scanRange ≥ 15
- 📡 Сигналы бедствия (distress_signal) — тип раскрывается сканером
- 🪼 Космические существа (space_monster) — вид и параметры раскрываются сканером

### Навигатор известных объектов

Сканер и посещения пополняют навигатор разведданными о локациях. Уже опознанный или посещённый объект остаётся доступен в поиске после поломки, демонтажа или замены сканера: изменения дальности влияют только на открытие новых сведений, а не стирают известные.

## 🪐 Сканирование планет

Планеты всегда видны на карте сектора, но **уровень детализации** в тултипе зависит от диапазона сканера:

| Диапазон | Видимая информация |
|----------|-------------------|
| **0** (без сканера) | Только название планеты |
| **≥ 3** | + Тип планеты (Пустынная, Ледяная, и т.д.) |
| **≥ 5** | + Статус колонизации (пустая/колонизированная) и раса населения |
| **≥ 8** | + Количество населения (в тысячах) |

### Примеры тултипов

**Без сканера (scanRange = 0):**
```
📍 Kepler-442b
```

**Сканер 1-2 уровня (scanRange = 3-4):**
```
📍 Kepler-442b
🏷️ Лесная
```

**Сканер 2-3 уровня (scanRange = 5-7):**
```
📍 Kepler-442b
🏷️ Лесная
🧬 Люди
```

**Сканер 3+ уровня (scanRange = 8+):**
```
📍 Kepler-442b
🏷️ Лесная
🧬 Люди

```

**Пустая планета (scanRange ≥ 5):**

## 🆘 Сканирование сигналов бедствия

Сигналы бедствия всегда видны на карте сектора, но **тип сигнала** раскрывается сканером, активным анализом или исследовательским зондом:

| Диапазон | Видимая информация |
|----------|-------------------|
| **0** (без сканера) | Только обозначение сигнала |
| **≥ 15** | + Вероятности типов: Засада (35%) / Выжившие (30%) / Груз (35%) |
| **Раскрыто сканером** | Конкретный тип: ⚔️ Засада пиратов / 👥 Выжившие / 📦 Заброшенный груз |

### Механика раскрытия

При первом входе в сектор происходит **одна попытка** раскрытия типа сигнала:
- Шанс зависит от диапазона сканера (0% при <3, до 95% при ≥20)
- Если успешно — `signalType` определяется и показывается в тултипе
- Если нет — показываются вероятности при scanRange ≥ 15

### Протоколы ответа

После неудачной автоматической проверки сигнал остаётся играбельной ситуацией, а не просто случайным выбором:

| Протокол | Требования | Результат |
|----------|------------|-----------|
| **Глубокое сканирование** | Сканер `≥3`, резерв энергии `≥2`, 1 ход | Одна дополнительная попытка раскрыть источник. Шанс: `25 + 3×диапазон + 8×уровни учёных + 4×уровни инженеров`, максимум 95%. |
| **Исследовательский зонд** | 1 зонд | Точно раскрывает источник сигнала и не тратит ход. |
| **Сближение с прикрытием** | Действующий инженер, заряженные щиты, резерв энергии `≥2`, 2 топлива | Страховка на случай засады: если сигнал оказывается пиратским, бой начинается без первого хода пиратов. Работает и для неизвестного сигнала, но топливо тратится в любом случае. |
| **Медицинская эвакуация** | Подтверждённые выжившие, действующий медик, 1 медикамент | Гарантирует 1–2 образца чужеродной биологии, повышает репутацию за спасение до +5 и шанс принять выжившего до 80%. |
| **Прямое сближение** | — | Базовый вариант без дополнительных затрат и защиты. |

В панели сигнала показываются диапазон сканера, резерв энергии, уровни специалистов и состояние щитов; недоступный протокол сразу объясняет, чего не хватает.

### Примеры тултипов

**Без сканера (scanRange = 0):**
```
🆘 Сигнал бедствия
```

**Квантовый сканер (scanRange ≥ 15, тип не раскрыт):**
```
🆘 Сигнал бедствия
⚡ Засада (35%) / Выжившие (30%) / Груз (35%)
```

**После раскрытия сканером:**
```
🆘 Сигнал бедствия
⚔️ Засада пиратов
```

## 🧮 Вычисление эффективного диапазона

### Формула

```typescript
эффективныйДиапазон = базовыйДиапазон + квантовыйБонус + технологическиеБонусы + сращиваниеКсеноморфа + бонусЗвезды
```

### Пошаговый расчёт

1. **Базовый диапазон** — максимальный `scanRange` среди активных модулей сканера
   - Если нет активных сканеров и нет артефакта "Глаз Сингулярности" → `0`
   - Если есть "Глаз Сингулярности" → `8`

2. **Бонус квантового сканера** — эффект артефакта `quantum_scan`, уже усиленный
   всеми множителями артефактов (исследования, кристаллический резонанс, черты
   экипажа, ритуал воидборнов)
   ```typescript
   if (quantumScanner) maxRange += getArtifactEffectValue(quantumScanner, state)
   ```

3. **Технологический бонус** — суммируются все изученные технологии с `scan_range`
   - Источники: технологии "Модуль сканера +1", "+2", "+3"
   - Формула: `maxRange += bonus1 + bonus2 + ...`
   - Пример: +1 +2 +3 = `maxRange + 6`

4. **Бонус сращивания ксеноморфа** — плоское добавление клеток от `mergeBonus.scanRange`, если экипаж сращён со сканером

5. **Бонус/колебание от типа звезды** — белый карлик даёт +2 к дальности, переменная звезда даёт колебание ±2 (детерминированное по номеру хода). Применяется только если у корабля уже есть базовый диапазон сканера > 0 (см. `src/game/constants/starEffects.ts`).

### Пример расчёта

**Конфигурация:**
- Сканер 3 уровня (диапазон 8)
- Квантовый сканер (артефакт, базовое значение 3)
- Все 3 технологии (+1, +2, +3 = +6)
- Трое в экипаже с кристаллическим резонансом (+15% каждый)

**Расчёт:**
1. База: `8`
2. Квантовый бонус: эффект артефакта `round(3 × 1.45) = 4` → `8 + 4 = 12`
3. Технологический бонус: `12 + 6 = 18`

**Итоговый диапазон:** `18`

Резонанс отдельной строкой не идёт: он уже внутри значения на шаге 2.

## 🎮 Механика обнаружения

### При входе в локацию

Когда игрок входит в локацию, игра проверяет возможность сканирования:

```typescript
// Псевдокод из store.ts
const canScanEnemy = canScanObject("enemy", enemyTier);

if (!canScanEnemy && !loc.signalRevealed) {
    // Попытка раннего предупреждения
    const detected = Math.random() * 100 < earlyWarningChance;
    
    if (detected) {
        startCombat(loc); // Игрок готов к бою
    } else {
        gameMode = "unknown_ship"; // Неизвестный корабль
    }
} else {
    startCombat(loc); // Прямой бой
}
```

### Типы объектов и реакция

| Тип объекта | Проверка сканера | При неудаче |
|-------------|------------------|-------------|
| 🚁 **enemy** | `canScanObject("enemy", tier)` | Шанс раннего предупреждения → unknown_ship |
| 👹 **boss** | `canScanObject("boss", 3)` | Шанс раннего предупреждения → unknown_ship |
| 🌀 **anomaly** | `canScanObject("anomaly", tier)` | unknown_ship |
| 🤝 **friendly_ship** | `canScanObject("friendly_ship")` | unknown_ship |
| 🌩️ **storm** | `canScanObject("storm")` | Вход без предупреждения |
| 📡 **distress_signal** | Раскрытие типа | Тип остаётся скрытым |

## ⚔️ Раннее предупреждение

### Обнаружение засады

Если сканер не может обнаружить объект, есть шанс **раннего предупреждения**:

| Угроза | Порог | Базовый шанс | Бонус за пункт диапазона | Максимум |
|--------|-------|--------------|-------------------------|----------|
| **Тир 1** | 3 | 10% | +3% | 80% |
| **Тир 2** | 5 | 8% | +2.5% | 80% |
| **Тир 3 / Босс** | 8 | 5% | +2% | 60-80% |

**Формула:**
```typescript
шанс = базовыйШанс + (диапазон - порог) × бонусЗаПункт
шанс = min(максимум, шанс)
```

**Пример для врага 1 тира с диапазоном 7:**
- База: 10%
- Бонус: (7 - 3) × 3% = 12%
- Итого: 10% + 12% = **22%**

### Обнаружение босса

Для боссов используется отдельная формула в `store.ts`:
- База: 5%
- Порог: 8
- Бонус: +2% за пункт выше 8
- Максимум: 60%

**Пример с диапазоном 12:**
- База: 5%
- Бонус: (12 - 8) × 2% = 8%
- Итого: 5% + 8% = **13%**

## 📡 Раскрытие типа сигнала бедствия

### Механика

При первом входе в локацию с сигналом бедствия происходит проверка:

```typescript
const revealChance = getSignalRevealChance();
const canReveal = Math.random() * 100 < revealChance;

if (canReveal) {
    // Определяется тип сигнала (ambush, trap, etc.)
    loc.signalType = determineSignalType();
    loc.signalRevealed = true;
}
```

### Шансы раскрытия

| Диапазон | Базовый шанс | Бонус за пункт | Максимум |
|----------|--------------|----------------|----------|
| **≥ 15** | 75% | +2% | 95% |
| **≥ 8** | 50% | +2% | 95% |
| **≥ 5** | 30% | +2% | 95% |
| **≥ 3** | 15% | +2% | 95% |
| **< 3** | 0% | — | — |

**Пример с диапазоном 10:**
- База (≥ 8): 50%
- Бонус: (10 - 8) × 2% = 4%
- Итого: 50% + 4% = **54%**

## 🔬 Влияние технологий

### Технологии с бонусом к сканированию

| Технология | Уровень | Бонус | Стоимость |
|------------|---------|-------|-----------|
| 📡 **Модуль сканера +1** | Tier 1 | +1 к диапазону | 250₢ + 3 древ.данных |
| 🌀 **Модуль сканера +2** | Tier 2 | +2 к диапазону | 600₢ + 8 древ.данных + 1 кристалл |
| 🔮 **Модуль сканера +3** | Tier 3 | +3 к диапазону | 700₢ + 15 древ.данных + 2 кристалла |

**Применение:**
- Бонусы технологий **суммируются** (аддитивно)
- Формула: `диапазон + бонус1 + бонус2 + ...`
- Пример: все 3 технологии = +1 +2 +3 = **+6 к диапазону**

## 🎯 Стратегия использования

### Ранняя игра
1. Установите **сканер 1-2 уровня** для базового обнаружения
2. Изучите **Модуль сканера +1** для +1 к диапазону
3. Фокусируйтесь на обнаружении врагов 1-2 тира

### Средняя игра
1. Модернизируйте до **сканера 3 уровня** (диапазон 8)
2. Получите артефакт **Квантовый сканер** (+3 к диапазону)
3. Изучите **Модуль сканера +2** для +2 к диапазону

### Поздняя игра
1. Установите **сканер 4 уровня** (диапазон 15)
2. Получите **Глаз Сингулярности** для резервного сканирования
3. Изучите **Модуль сканера +3** для +3 к диапазону
4. Максимальный диапазон: **28+** со всеми бонусами
