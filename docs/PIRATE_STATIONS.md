# Пиратские станции и розыск

Пиратские станции дают доступ к чёрному рынку, отмывке следов и доске задач. Они не проводят досмотр и не заменяют обычные торговые, модульные или экипажные разделы.

В разделе «Торговля» навигатора фильтр «Только чёрный рынок» показывает только уже известные пиратские станции. Цены появляются после посещения станции; для контрабанды это фактический чёрнорыночный спред, а обычные товары остаются доступным дешёвым, но не гарантированно самым дешёвым источником.

## Разыскиваемость

`wantedHeat` — общий для забега счётчик от 0 до 100. Он сохраняется вместе с игрой; при загрузке старого сохранения берётся наибольшее значение прежнего локального `pirateHeat`.
Старые пиратские заказы очищаются при миграции: в них не было настоящих целей, поэтому доска безопасно обновится при следующем визите, а обычные контракты сохранятся.

| Событие | Изменение |
| --- | ---: |
| Покупка или продажа контрабанды | +4 |
| Передача контрабанды по пиратской задаче | +8 |
| Налёт зондом на легальную станцию | +15 |
| Просроченная пиратская задача | +10 |
| Сдача пиратской задачи | −20 |
| Отмывка на пиратской станции за 500₢ | −15 |

Начиная с 50, обычная станция останавливает игрока на досмотре. Можно дать взятку за `200 + (розыск − 49) × 15` кредитов, выбросить всю контрабанду или отступить; первые два варианта снижают значение до 45. Начиная с 75 доступен бой с охотниками за головами. Победа снижает розыск до 25.

## Пиратские задачи

Доска создаётся после полной генерации галактики, поэтому у каждой задачи есть реальная цель и сектор:

- Контрабанда: довезти нужный объём на легальную станцию и передать его там.
- Заказ на голову: уничтожить конкретный вражеский корабль.
- Налёт: прибыть на легальную станцию и потратить зонд на операцию.

Налёт всегда выполняется после траты зонда: отдельного шанса «уйти незамеченным» нет, а его детерминированный след — `+15` к розыску.

После выполнения цели награда выдаётся только на станции-заказчике. Срок для любой пиратской задачи равен `12 + 2 × уровень сектора` ходов. Цель, её сектор, заказчик и его сектор показываются на доске, в списке контрактов и на карте. Предложения доски обновляются при следующем посещении той же пиратской станции, если прошло не менее 50 ходов; принятая задача остаётся на доске заказчика даже после обновления предложений.
