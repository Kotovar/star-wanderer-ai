# Дипломатические соглашения рас

## Цель

Сделать репутацию каждой расы самостоятельной стратегической целью, не меняя существующие планетарные специализации.

## Правила

- Соглашение активно, когда репутация расы находится на уровне `friendly` или `allied` (от `+11`).
- При снижении репутации до `+10` или ниже соглашение сразу приостанавливается.
- Соглашение не записывается в сохранение: его состояние всегда выводится из текущей репутации.
- Планетарные специализации при уровне `allied` (`+51`) не меняются и не считаются соглашениями.

| Раса | Соглашение | Механический эффект |
|---|---|---|
| Люди | Логистический пакт | `+2` хода к каждому срочному контракту при принятии |
| Синтетики | Обмен данными | `+10%` к итоговой производительности исследований |
| Ксеносимбионты | Медицинский договор | `−15%` к цене лечения экипажа |
| Крилорианцы | Протокол эвакуации | `+5` процентных пунктов к шансу отступления |
| Пусторождённые | Звёздные карты | `−8%` к расходу топлива |
| Кристаллические | Резонансная сеть | `+1` процентный пункт к попытке найти артефакт |

## Онбординг

- При первом принятии контракта с несколькими репутационными последствиями игра один раз объясняет, что последствия видны до принятия и затрагивают известные союзные и враждебные расы.
- При переходе основной расы через порог `+11` журнал сообщает об открытом соглашении; при падении ниже порога — о его приостановке.
- Карточка известной расы показывает активное соглашение или точное число очков до его открытия.

## Границы

- Не добавлять новый экран или шаг в `WelcomeTutorial`.
- Не добавлять новое поле в `GameState`, миграцию сохранений, валюту, кулдаун или активируемые способности.
- Не повышать прямой урон, боевые награды или цены продажи.

## Проверка готовности

- Соглашения активируются на `+11` и остаются активными на `+51`.
- Каждый из шести эффектов меняет только свой существующий расчёт.
- Репутационная панель и все новые сообщения локализованы на русском и английском.
- Проходят `npm run check:race-agreements`, `npm run check:reputation`, `npm run type-check` и `npm run lint`.
