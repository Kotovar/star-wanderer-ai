# Дипломатические последствия

Изменение репутации с одной расой влияет на её союзников и соперников. Вторичное изменение рассчитывается по отношению расы:

`округление(фактически применённое основное изменение × отношение / 50)`

Например, выполнение расового контракта с наградой `+10` репутации даёт `-4` расе с отношением `-20` и `+3` расе с отношением `+15`.

Если основная репутация уже упёрлась в предел `[-100, 100]`, ряби нет. Вторичные изменения применяются только к уже открытым расам. Последствия показываются на карточке контракта до принятия и записываются в журнал после принятия; карточка считает их из текущих значений тем же порядком, что и фактическое завершение. Доктрина не отменяет дипломатические последствия.

Обычный нерасовый контракт с репутационной наградой даёт основной расе `+2`. Если уже сгенерированная охота за наградой получена с доски расы уровня «дружелюбные» или «союз», она платит на 25% больше кредитов и даёт основной расе `+4`. Вторичные изменения для этой повышенной награды рассчитываются тем же обычным механизмом ряби.

Расовые контракты требуют нейтральной репутации или выше; обычные контракты не получают этого ограничения. Контракт отклика на кризис последовательно даёт заказчику `+4`, затем каждой другой известной расе `+2`; каждый шаг вызывает обычную рябь, а карточка показывает итоговые изменения.

Фракционная доставка у цели даёт явный выбор: выполнить хартию — обычные `+2` расе-заказчику, либо передать груз местным — ровно `+4` местной расе и `-4` заказчику. Для местного выбора две прямые стороны исключаются из ряби друг друга, поэтому эти значения не сокращаются; все третьи расы всё ещё получают обычную сумму дипломатических рябей, которая показывается в существующем окне завершения контракта.

Помощь дружественному кораблю в бедствии даёт его расе `+2` репутации и запускает обычную рябь по уже открытым расам; награда показана до подтверждения.
