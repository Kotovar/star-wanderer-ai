# Звуковая система

Рантайм использует только нативный Web Audio API и файлы OGG/Opus. Музыка и
эффекты загружаются лениво из `public/audio`, не требуют зависимостей в
клиентском бандле и корректно молчат при ошибке загрузки/декодирования.

## Исходники и генерация

- `audio/source/music/space-exploration.mjs` — оригинальная детерминированная
  партитура: 96 секунд, 64 BPM, низкие дроны, медленное движение гармонии,
  фильтрованная текстура и редкий пульс. Это бесшовная exploration-петля без
  лид-мелодии и боевого слоя.
- `audio/source/sfx/presets.mjs` — явные пресеты и варианты эффектов.
- `scripts/generate-audio.mjs` — рендерит временные WAV, отклоняет клиппинг
  jsfxr, добавляет короткие fade/limiter через ffmpeg и кодирует Opus.
- `src/sounds/utils.ts` — типизированный реестр и единый сервис микширования.

```bash
npm run audio:generate
npm run check:audio
```

Не редактируйте `public/audio/**` вручную: это воспроизводимый результат
генератора. `check:audio` проверяет все URL реестра, OGG-заголовки и Opus-кодек,
длину музыки, обязательные варианты часто повторяемых эффектов и пиковый
уровень.

## Микс и настройки

Сигнал проходит через `master → music / sfx / ui`. Значения по умолчанию:

| Шина | Значение |
| --- | ---: |
| Master | 0.80 |
| Music | 0.45 |
| SFX | 0.70 |
| UI | 0.45 |

Музыка нормализуется около -26 LUFS; генератор ограничивает выход примерно
-2 dBTP. Внутри реестра опасные боевые события имеют выше gain, обычные эффекты
и UI — ниже. Сервис кэширует декодированные буферы, ограничивает число голосов
на эффект и глобально, а музыка имеет один активный source и fade 1.5 секунды.
`soundEnabled` остаётся общим mute, а уровни хранятся в сохранении.

## Добавление эффекта

1. Добавьте явный пресет в `audio/source/sfx/presets.mjs`.
2. Добавьте семантический ID, URL и категорию в `SOUND_REGISTRY`.
3. Вызовите `playSound("...")` или `playUi("...")` в реальном событии, а не
   в общем обработчике каждой кнопки.
4. Запустите `npm run audio:generate` и `npm run check:audio`.

Названия должны описывать событие (`combat_laser`, `travel_arrival`,
`world_discovery`, `ui_confirm`), а не акустический приём.

## Происхождение и границы

Все звуки создаются из исходного кода этого репозитория: музыка — из собственной
текстовой партитуры, эффекты — из собственных параметров jsfxr. `jsfxr` — только
devDependency для воспроизводимой генерации; в рантайм он не попадает. В проект
не добавляются Strudel-код, сторонние sample banks или готовые сэмплы, поэтому
нет зависимости от их лицензий/условий распространения.

В этой итерации намеренно нет динамических боевых слоёв, интенсивностной музыки
и звуков docking/undocking: для последнего в игре нет отдельного события.
