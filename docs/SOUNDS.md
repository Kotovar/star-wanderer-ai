# Звуковая система

Рантайм использует только нативный Web Audio API и файлы OGG/Opus. Музыка и
эффекты загружаются лениво из `public/audio`, не требуют зависимостей в
клиентском бандле и корректно молчат при ошибке загрузки/декодирования.

## Исходники и генерация

Все эффекты и музыка сгенерированы локально в AI Studio моделью
Stable Audio 3 Medium (`stable-audio-3-medium-sfx` для эффектов,
`stable-audio-3-medium` для музыки).

- `audio/source/ai-audio.json` — манифест: для каждого файла `public/audio`
  записаны промпт, seed, длительность запроса, модель и asset id в библиотеке
  студии. По нему можно перегенерировать или заменить отдельный звук.
- `scripts/import-audio.mjs` — берёт WAV из библиотеки AI Studio
  (`AI_STUDIO_LIBRARY`, по умолчанию `/mnt/filestorage/ai-studio/library`) и
  кодирует Opus: у эффектов срезает тишину по краям, ставит короткие фейды и
  нормализует пик (−3.5 dB, UI −5 dB); музыку зацикливает кроссфейдом хвоста
  в начало (4 с) и нормализует до −23 LUFS.
- `src/sounds/utils.ts` — типизированный реестр и единый сервис микширования.

```bash
npm run audio:import
npm run check:audio
```

Не редактируйте `public/audio/**` вручную: замена звука — новая генерация в
AI Studio, обновление записи в манифесте и `npm run audio:import`.
`check:audio` сверяет реестр с манифестом, проверяет OGG/Opus, длину музыки
(60–120 с), обязательные варианты частых эффектов, пиковый уровень и громкость
эффектов в миксе по умолчанию.

## Музыка

| ID | Когда играет |
| --- | --- |
| `title` | титульный экран и стартовое меню |
| `exploration` | обычная игра вне остальных контекстов |
| `combat` | обычный бой и окно результатов боя |
| `boss` | бой с боссом (`enemy.isBoss`) и окно результатов этого боя |
| `expedition` | экспедиция на поверхность планеты (`activeExpedition`) |
| `dive` | погружение в газовый гигант (`activeDive`) |
| `storm` | шторм (`gameMode` `storm` / `storm_results`) |
| `station_<раса>` | станция этой расы (`dominantRace`) |
| `station` | станция без расы (дипломатическая) |
| `planet_<раса>` | населённая планета этой расы |
| `planet_empty` | пустая планета (`isEmpty`) |
| `crisis` | глобальный кризис (`activeCrisis`) вместо `exploration` |

Приоритет: титул → бой → экспедиция → погружение → шторм → станция →
планета → кризис → exploration (см. `pickSceneMusic` в `src/app/page.tsx`).

У каждого контекста несколько треков (`space-<id>.ogg`, `space-<id>-2.ogg`, …):
при входе в контекст выбирается случайный, а после полного проигрыша трек
кроссфейдом сменяется другим из того же набора. Победный залп сразу обнуляет
`currentCombat`, поэтому боевая музыка держится, пока `gameMode` равен
`battle_results`.

## Микс и настройки

Сигнал проходит через `master → music / sfx / ui`. Значения по умолчанию:

| Шина | Значение |
| --- | ---: |
| Master | 0.80 |
| Music | 0.45 |
| SFX | 0.70 |
| UI | 0.45 |

Музыка нормализуется до -23 LUFS; импорт ограничивает выход примерно
-3 dBTP. Внутри реестра опасные боевые события имеют выше gain, обычные эффекты
и UI — ниже. Сервис кэширует декодированные буферы, ограничивает число голосов
на эффект и глобально, а музыка имеет один активный source и fade 1.5 секунды.
Для каждого контекста зарегистрирована отдельная петля; переход между ними
ограничен двумя source на коротком crossfade, а не постоянным боевым
слоем. `soundEnabled` остаётся общим mute, а уровни хранятся в сохранении.

## Добавление эффекта

1. Сгенерируйте звук в AI Studio (английский промпт, 0.3–3 с) и добавьте
   запись в `audio/source/ai-audio.json`.
2. Добавьте семантический ID, URL и категорию в `SOUND_REGISTRY`.
3. Вызовите `playSound("...")` или `playUi("...")` в реальном событии, а не
   в общем обработчике каждой кнопки.
4. Запустите `npm run audio:import` и `npm run check:audio`.

Названия должны описывать событие (`combat_laser`, `travel_arrival`,
`world_discovery`, `ui_confirm`), а не акустический приём.

## Происхождение и границы

Звуки — результат локальной генерации Stable Audio 3 по промптам из
манифеста; сторонние сэмплы и sample banks не используются. Перед публичным
релизом стоит сверить условия лицензии Stable Audio для коммерческого
использования сгенерированного аудио.

В этой итерации намеренно нет динамических боевых слоёв и звуков
docking/undocking: для последнего в игре нет отдельного события.
