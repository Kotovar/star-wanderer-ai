# Компоновка корабля

## Направление и хребет

Верх сетки 5×5 — нос, низ — корма. Корпус должен оставаться связанным и иметь путь «кабина → реактор → двигатель» с критическими модулями в этом порядке по вертикали.

## Внешний контур

Кабине нужен свободный сектор спереди, двигателю — сзади, оружейной палубе — с любой стороны. Модуль с открытой стороной считается внешним.

## Бой

Внешний модуль получает +20 к приоритету выбора цели противником. Урон не увеличивается, внутренние модули не становятся неуязвимыми.

## Старые сохранения

Старая схема продолжает работать. Перемещение может сохранить существующее нарушение, но не добавить новое; исправленное нарушение нельзя вернуть.
