# Арки профилей забега

## Цель

Сделать каждый профиль галактики отдельным направлением прохождения: игрок
выбирает маршрут по характерным локациям профиля и получает одну тематическую
награду внутри текущего забега.

## Механика

Каждый профиль получает арку из трёх видимых порогов: 1, 3 и 5 изученных
локаций. Локация засчитывается по тем же признакам, что и счётчик посещённых
локаций в прогрессе кампании: посещение, победа, исследование, разведка или
другой сохранённый результат взаимодействия.

| Профиль | Засчитываемые локации | Награда за 5 локаций |
| --- | --- | --- |
| Древний след | аномалия, газовый гигант | 6 древних данных, 1 квантовый кристалл |
| Военная спираль | враг, космическое существо | 5 образцов инопланетной биологии, 3 тех. лома |
| Угасающая галактика | дереликт, сигнал бедствия, поле обломков | 5 редких минералов, 3 тех. лома |

После достижения третьего порога в панели прогресса появляется одна кнопка
получения награды. Награда не выдаётся автоматически: игрок сам подтверждает
её получение и видит запись в журнале. Повторное получение невозможно.

## Данные и состояние

- Конфигурация арки живёт рядом с генерационными весами в `runProfiles.ts`:
  типы локаций, пороги, ключи локализации и пакет исследовательских ресурсов.
- Чистый helper считает число засчитанных локаций и достигнутый порог из
  `runProfileId`, `galaxy.sectors` и `completedLocations`.
- В `GameState` добавляется единственный флаг `runProfileArcRewardClaimed`.
  Публичный action повторно проверяет порог перед выдачей ресурсов, увеличивает
  соответствующие `research.resources`, устанавливает флаг и пишет в журнал.
- Новая игра сбрасывает флаг. Версия сохранения повышается с 18 до 19;
  миграция для старых сохранений задаёт `false`. Забеги без профиля не имеют
  арки и не показывают кнопку.

## Интерфейс

Существующий блок «Профиль забега» в `CampaignProgressPanel` дополняется
тремя компактными этапами и прогрессом `n/5`. Завершённые этапы выделяются
зелёным, текущий — янтарным. Вся копия и имена ресурсов локализованы на
русский и английский.

## Ограничения

- Не добавлять отдельный тип контрактов, новую валюту, постоянные пассивные
  эффекты, мета-разблокировки или второй экран заданий.
- Не менять идентификаторы профилей, их генерационные веса, баланс обычных
  наград, шапку игры и существующие цели победы.
- Обновить `docs/CAMPAIGN_PROGRESSION.md`: новое имя «Угасающая галактика» и
  описание арок.

## Проверка

- Новый `npm run check:run-profile-arcs` проверяет пороги, все три пакета,
  отсутствие прогресса без профиля, одноразовость action и миграцию v18 → v19.
- `npm run check:run-profiles`, `npm run type-check`, `npm run lint` и
  `git diff --check` проходят без ошибок.
