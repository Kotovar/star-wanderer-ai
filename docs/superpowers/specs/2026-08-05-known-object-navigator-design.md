# Навигатор известных объектов

**Статус: реализовано.** Фильтр качества кандидатов на найм отложен по решению продукта.

## Цель

Дать игроку один раздел для поиска уже известных целей и установки отметок на карту. Отдельную механику продажи, новых торговцев и изменение частоты станций не добавлять: навигатор должен находить доступные торговые станции и дружественные корабли-торговцы.

## Граница знания

Навигатор никогда не читает процедурно сгенерированные свойства локации как уже известные игроку. При входе в сектор и открытии карты игра сохраняет разведданные о каждой видимой локации с тем уровнем подробностей, который дал текущий сканер. Посещение локации повышает запись до `visited`.

Запись разведданных хранит идентификаторы сектора и локации, тир сектора и максимальные известные подробности. Значения остаются единственным источником правды в `Location`; запись лишь определяет, какие из них разрешено показывать. Для планет это отдельные ступени сканирования `0/3/5/8`; для остальных объектов — `seen`, `identified`, `visited`.

Текущие сведения, которые меняются вследствие действий игрока (например, побеждён ли враг, исчерпаны ли обломки), читаются из локации, но только если соответствующий объект уже есть в разведданных. Старые сохранения начинают с посещённых локаций и известных торговых станций; остальная информация открывается обычным сканированием.

## Интерфейс

Из глобального HUD открывается панель «Навигатор» и возвращает игрока в предыдущий режим при закрытии. Панель содержит поиск по имени и пять компактных категорий:

- **Торговля** — станции с известной торговлей и опознанные дружественные торговцы. По товару выводятся известные точки с ценами покупки и продажи; цена показывается только после стыковки с этой станцией или контакта с кораблём. Кнопка «Продать из трюма» выводит только товары с корабля, показывает их количество и сортирует известные точки по цене продажи.
- **Найм** — станции и корабли, где уже открыт состав кандидатов. Фильтры: раса, профессия, уровень, черта и мутация. Результат учитывает текущую доступность найма и уже нанятых кандидатов.
- **Планеты** — тип, населённость, раса, отношение и тир. Каждый критерий доступен лишь после соответствующей ступени разведданных.
- **Задания и угрозы** — известные квесты, не побеждённые боссы и враги.
- **Исследование и добыча** — опознанные корабли, объекты, аномалии, штормы, сигналы, обломки, астероиды и космические существа; фильтр «не обработано» использует их текущее состояние.

Фильтр тира предлагает 1–3 и добавляет 4 только по существующему правилу открытия четвёртого тира. Пустой результат объясняет, что подходящих известных целей нет.

## Отметки

У каждой строки есть переключатель отметки. Отмеченные цели сохраняются в забеге и управляются из того же списка: снять одну отметку или очистить все.

На карте галактики отметки группируются по секторам. На карте сектора каждая известная цель подсвечивается поверх своей локации. Для рисования расширяется существующий слой маркеров целей; автопрокладки маршрута, расхода топлива и нового режима перемещения нет.

## Модель данных и реализация

В `GameState` добавляются только две сохранённые коллекции: разведданные по известным локациям и массив отмеченных пар «сектор—локация». Поиск — чистая проекция этих коллекций, `galaxy.sectors`, известных цен и детерминированно сгенерированных составов станции; отдельный индекс, сервер или новая зависимость не нужны.

Обновление разведданных находится в одном общем helper пути входа/сканирования сектора, а не в каждом компоненте карты. Маркеры получают один общий селектор для GalaxyMap и SectorMap.

## Проверка

- Проверка helper: неизвестный объект не попадает в поиск; объект остаётся доступен после поломки или замены сканера; старое сохранение мигрирует без раскрытия новых целей.
- Проверка проекции: ресурс показывает только известные цены, а фильтры найма не выводят не открытый состав.
- Проверка отметок: добавить несколько целей, снять одну, очистить все; GalaxyMap группирует сектор, SectorMap отмечает точные локации.
- Обязательные команды: `npm run type-check`, `npm run lint`, `git diff --check`.

## Вне среза

Новые торговцы, изменение частоты станций, динамическая экономика, автопилот, оценка маршрута по топливу, поиск по неоткрытой галактике и пользовательские категории/метки.
