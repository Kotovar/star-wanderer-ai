# Единичная торговля газом

## Цель

Дать игроку точный контроль над небольшими остатками газа на станции: продавать
одну единицу, не избавляясь от всего запаса, и покупать один полимер, не занимая
лишнее место в трюме.

## Решение

- Для каждого продаваемого газа рядом с `Продать всё` появляется кнопка
  `Продать 1`.
- Для покупки синтез-полимеров набор кнопок меняется с `+5 / +10` на
  `+1 / +5 / +10`.
- Обе кнопки используют существующие `sellGas` и `buyGas` с количеством `1`.
  Цены, ограничения трюма и проверка кредитов не меняются.
- Для `Продать 1` добавляется локализованная подпись в RU и EN. Новое состояние,
  поле количества и отдельная торговая логика не нужны.

## Не входит в объём

Произвольный ввод количества, степпер, изменение курсов и торговля криогеном.

## Проверка

Расширить существующий реальный render-check `scripts/check-player-feedback.mjs`
компонентом `GasSaleSection`: для доступного газа должны отображаться
`Продать 1`, `Продать всё` и кнопки покупки `+1 / +5 / +10`. Затем прогнать
профильную проверку, type-check, lint и `git diff --check`.
