# Докосмические цивилизации на пустых планетах

**Дата:** 2026-08-13
**Статус:** согласовано, ожидает обзора перед планом реализации

## Цель

Редкая пустая планета может оказаться домом для локальной докосмической цивилизации. Игрок находит её во время планетарной экспедиции, а затем взаимодействует с ней через компактную панель на той же планете.

Это не новая космическая фракция: у цивилизации нет глобальной репутации, контрактов, рынка, найма или выхода в космос. История остаётся привязанной к одной планете.

## Границы

- Только полностью разведанные пустые планеты, на которых уже доступна экспедиция.
- Только одна цивилизация на планету.
- Нет новых валют, глобальных эффектов, таймеров доверия и повторяемого фарма наград.
- Открытое поселение и база взаимоисключающие:
  - на планете с поселением нельзя строить базу;
  - на планете с существующей базой поселение не появляется.
- Старые сохранения не получают поселения задним числом.

## Появление поселения

Для подходящей пустой планеты из `planetId` детерминированно выбираются:

1. Наличие поселения с вероятностью 20%.
2. Одна культура и её уровень развития.
3. Одна из четырёх клеток, смежных с центральной зоной высадки.

Детерминированный выбор не позволяет перебрасывать наличие или тип цивилизации отменой экспедиции либо загрузкой сохранения. Поселение добавляется в свежую экспедиционную сетку как единственная клетка `settlement`; центральная клетка остаётся обычной зоной высадки.

Перед вставкой клетки игра проверяет и `location.outpostId`, и список `outposts` по `locationId`. При наличии базы сетка генерируется без поселения.

## Уровни развития

Начальный каталог содержит по одной культуре на каждый уровень. Он хранится как статические данные, а не как `Race`.

| Уровень | Характер контакта |
| --- | --- |
| Первобытный | Наблюдение издалека, непрямые дары, охранный заповедник. |
| Аграрный | Осторожное посредничество, помощь в локальном кризисе, автономия. |
| Индустриальный | Формальные переговоры, ограниченная материальная помощь, культурная изоляция. |
| Современный | Радиодиалог, научный обмен, договор об автономии. |

Уровень влияет на текст, доступные способы контакта, требуемые существующие грузы и одноразовые награды. Он не меняет число этапов и не использует тир сектора.

## Цепочка контакта

Открытие клетки тратит обычный AP экспедиции, записывает контакт в планету и показывает диалог находки. Оно не выдаёт награду само по себе и не теряется при отмене экспедиции.

Дальше на панели пустой планеты доступны ровно три последовательных действия. Каждое успешное действие тратит один обычный ход.

1. **Наблюдение.** Безопасное изучение цивилизации и небольшой одноразовый исследовательский результат, зависящий от её уровня.
2. **Первый контакт.** Уровнеспецифичная этическая развилка: например, непрямая помощь первобытной культуре, посредничество с аграрной или радиосвязь с современной. Помощь может расходовать только существующий груз: `food`, `medicine` или `spares`. Невмешательство также остаётся валидным путём.
3. **Граница контакта.** Игрок фиксирует локальный итог: защита автономии, поддержка развития или ограниченное партнёрство. Варианты дают сопоставимые одноразовые результаты разного типа, а не один очевидно выгодный выбор.

После третьего действия интерфейс показывает постоянный статус поселения и итог истории. Награды не повторяются; постоянный локальный результат — сохранённый статус контакта и запрет базы на этой планете.

## Данные и состояние

В `Location` добавляется необязательное поле контакта:

```ts
type PreSpacefaringDevelopment =
  | "primitive"
  | "agrarian"
  | "industrial"
  | "modern";

interface PreSpacefaringContact {
  civilizationId: string;
  development: PreSpacefaringDevelopment;
  step: 0 | 1 | 2 | 3;
  outcome?: "protected" | "assisted" | "partnered";
}
```

Клетка `settlement` несёт идентификатор и уровень выбранной культуры до открытия. При открытии эти данные единожды переносятся в `Location`; далее источником истины становится `Location.preSpacefaringContact`.

Новые поля необязательны, поэтому старые сохранения остаются корректными без миграции и без повышения версии сохранения. Если позднее понадобится ретроактивно добавить поселения в старые миры, это будет отдельным решением с миграцией.

## Архитектура

- `src/game/constants/...`: небольшой каталог культур, этапов и уровнеспецифичных действий.
- `src/game/types/exploration.ts`: новый тип клетки и её данные-кандидат.
- `src/game/types/locations/locations.ts`: необязательное сохранённое состояние контакта.
- `src/game/slices/locations/helpers/expedition/...`: детерминированная вставка клетки и обработка её открытия.
- `src/game/slices/locations/...`: одно публичное действие продвижения контакта; большая проверка и применение результата остаются в helper.
- `src/game/components/EmptyPlanetPanel.tsx`: существующая карточка точки интереса заменяется компактной карточкой контакта после открытия поселения. При необходимости она использует маленький дочерний компонент, а не новый экран.
- `src/game/slices/outposts/helpers/canBuildBase.ts`: общий запрет строительства базы.
- `src/lib/locales/ru.json` и `src/lib/locales/en.json`: все новые пользовательские тексты, включая причину блокировки базы.
- `docs/EXPEDITION_SYSTEM.md`: описание новой клетки и взаимного запрета базы/поселения.

## Валидация и ошибки

Публичное действие контакта до изменения состояния проверяет:

- существует ли текущая пустая планета и её контакт;
- совпадает ли ожидаемый шаг;
- разрешён ли выбранный вариант для уровня развития;
- есть ли требуемый груз;
- не завершён ли этот этап ранее;
- нет ли базы на планете.

При любой невалидной попытке игра не тратит ход, не выдаёт награду и не изменяет контакт. UI отключает недоступный вариант с локализованной причиной, но helper остаётся окончательной защитой от повторного клика и устаревшего состояния.

`getBaseBlocker` получает новое значение `settlement_discovered`. Поэтому и `BaseSection`, и `buildBase` одинаково блокируют постройку и не списывают кредиты или ресурсы. Обратная проверка в генерации и открытии поселения не допускает появления контакта на базе.

## Проверки

Добавляется одна небольшая проверка, `scripts/check-pre-spacefaring-civilizations.mjs`, которая подтверждает:

- детерминированный выбор поселения, культуры, уровня и доступной смежной клетки;
- отсутствие клетки на планете с базой;
- создание контакта при открытии клетки и его сохранение после отмены экспедиции;
- ровно три последовательных этапа для каждого уровня;
- невозможность повторно получить награду или потратить ход при невалидном действии;
- запрет строительства базы на планете с поселением без списания ресурсов.

Перед завершением реализации запускаются:

- `npm run check:pre-spacefaring-civilizations`
- `npm run check:expedition-tiles`
- `npm run check:expedition-abort`
- `npm run check:base`
- `npm run type-check`
- `npm run lint`
- `git diff --check`

## Отложено намеренно

- Несколько культур на каждый уровень развития.
- Визуальные портреты, новые спрайты и отдельный экран цивилизации.
- Глобальная дипломатия, торговля, найм, контракты или космический выход поселения.
- Ретроактивная генерация поселений в старых сохранениях.

Эти расширения добавляются только если базовая локальная цепочка окажется достаточно интересной в игре.
