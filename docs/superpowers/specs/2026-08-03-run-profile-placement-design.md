# Размещение профиля забега

## Цель

Показывать профиль забега там, где игрок отслеживает кампанию, а не поверх
галактической карты.

## Изменения

- Убрать бейдж профиля из `GalaxyMap`.
- В `CampaignProgressPanel` добавить блок с текущим профилем: иконка, название,
  возможность и риск из существующих ключей локализации.
- Оставить краткий бейдж профиля в шапке игры.
- Переименовать отображаемый профиль `broken_trade_lanes` в «Угасающая
  галактика» / `Fading Galaxy`.

## Ограничения

- Идентификатор `broken_trade_lanes`, генерация мира, баланс и формат
  сохранений не меняются.
- Для старых сохранений без профиля новый блок не рендерится.

## Проверка

- `npm run type-check`
- `npm run lint`
- `git diff --check`
