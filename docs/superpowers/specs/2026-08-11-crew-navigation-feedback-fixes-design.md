# Исправления экипажа, навигации и обратной связи — дизайн

## Scope

Исправить подтверждённые игровые и UI-дефекты без ребаланса аномалий. Пункт 7
исходного списка (различия подходов к аномалиям) намеренно отложен.

1. Автоматика учёного предпочитает лабораторию.
2. «Наука» возвращает к предыдущему экрану, включая панель планеты.
3. Уровни учёного для исследования артефактов зависят от редкости.
4. Исправляется русская строка отложенного последствия торговца.
5. Завершение или отмена поверхностной экспедиции выполняет обычный тик хода.
6. Модальное событие газового гиганта не меняет размеры его панели.
7. Имена планет в целях поставки локализуются.
8. Небиологические кандидаты наёмников не получают мутации.
9. Результат подавления кризиса виден сразу.
10. Готовность экипажа в центре кризисов не показывает `NaN%`.

Метка «дефицит ×2» не меняется: при активном кризисе она умножает на два
покупную и продажную цену указанного товара.

## Confirmed causes

- Планировщик автоматики назначает учёных в лабораторию только при активном
  исследовании; иначе свободный учёный уходит к сканеру.
- `showResearch()` сохраняет `previousGameMode`, но `ResearchPanel` и кнопка
  науки в шапке вызывают `showSectorMap()` вместо `closeResearchPanel()`.
- Данные артефактов содержат старые индивидуальные уровни, включая разные
  уровни проклятых артефактов.
- В русском каталоге строки торговца осталось слово `Recommend`.
- Финализатор экспедиции увеличивает `turn` напрямую, минуя `nextTurn()` и
  автоматику экипажа.
- При `currentEvent` панель газового гиганта удаляет весь блок кнопок; при
  изменении высоты появляется/исчезает скроллбар и меняет доступную ширину.
- `ContractsList` выводит `sourceName` поставки как строку, не применяя
  `getLocationName()`.
- Общий генератор черт для найма не применяет правило небиологических рас,
  хотя оно уже есть в `giveRandomMutation()`.
- `resolveCrisis()` пишет успех или провал только в журнал, хотя в приложении
  уже настроен `sonner`.
- Формула готовности делит мораль синтетика `0` на `maxHappiness = 0`.

## Design

### Экипаж, артефакты и экспедиция

- В мирном режиме слот лаборатории получает свободного учёного и без активной
  технологии. При активной технологии его задача — `research`; без неё задача
  отсутствует, поэтому усталость за работу не начисляется. Сканер остаётся
  следующим приоритетом, а на дефицитные слоты по-прежнему выбирается учёный
  высокого уровня.
- В константах артефактов устанавливаются уровни: `rare` и `cursed` — 3,
  `legendary` — 4, `mythic` — 5. Механизм проверки и UI уже используют поле
  `requiresScientistLevel`, поэтому новых типов и состояния нет.
- Экспедиция сначала фиксирует награды/состояние планеты и очищает
  `activeExpedition`, затем вызывает существующий `nextTurn()`. Возвращаемые
  экипажу усталость и потеря морали применяются после этого тика, сохраняя
  полные пять ходов усталости. Это даёт автоматике ровно один обычный шаг.
- `generateCrewTraits()` применяет существующий признак небиологической расы,
  а `buildCrewMember()` передаёт в него профессию и расу. Так правило работает
  для всех источников найма, не только дружеского корабля.

### Навигация, строки и кризисы

- Все выходы из панели исследования используют `closeResearchPanel()`.
- Русская строка последствия торговца исправляется без смены ключа.
- Поставки и другие отображения `sourceName` пропускают имя через
  `getLocationName()`.
- Успех подавления кризиса вызывает `toast.success`, провал — `toast.error`;
  журнал остаётся источником истории. Новая модалка и новое сохранённое
  состояние не нужны.
- Готовность члена экипажа с `maxHappiness = 0` равна его доле здоровья;
  остальные продолжают использовать среднее здоровья и морали.

### Газовый гигант

- Корневой скролл-контейнер резервирует место под полосу прокрутки.
- Во время обязательного выбора слот погружения и всплытия остаётся в разметке
  заблокированным. Модальное окно по-прежнему не позволяет нажать эти кнопки.

## Boundaries

Не меняются награды или риски аномалий, цены и коэффициенты дефицита,
генерация экспедиций, правила ручных назначений и данные сохранений. Новые
зависимости, роуты, глобальное состояние и отдельные компоненты модалок не
добавляются.

## Verification

Сначала добавляются регрессионные проверки для лабораторного приоритета,
небиологического кандидата, единственного тика экспедиции, уровней артефактов,
перевода цели поставки и расчёта готовности. Для газового гиганта проверяется
стабильность разметки и визуально — desktop-сценарий модального события.

После изменений запускаются целевые проверки, `npm run type-check`,
`npm run lint` и `git diff --check`. Документы о назначениях, исследованиях и
экспедициях обновляются вместе с поведением.
