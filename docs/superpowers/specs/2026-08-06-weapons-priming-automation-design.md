# Автоматика подготовки оружия

## Цель

В мирном режиме автоматическое управление должно поручать стрелку `clean_weapons`, только когда эффект `weapons_primed` отсутствует. При активном эффекте стрелок продолжает `training`.

## Поток

`runCrewAutomation` передаёт в планировщик булево значение наличия `weapons_primed` среди активных эффектов. Планировщик сохраняет существующий выбор оружейной палубы и самого опытного стрелка при дефиците слотов, но выбирает задачу `clean_weapons` вместо `training`, если баффа нет.

В бою поведение не меняется: стрелок получает `targeting`, затем свободные стрелки — `interception` в ПВО.

## Границы

- Не добавлять прогноз угроз, новых настроек или новых эффектов.
- Не обновлять длительность баффа, пока он активен: это оставляет `training` источником опыта между циклами подготовки.
- Добавить проверку двух мирных случаев: без баффа назначается `clean_weapons`, с баффом — `training`.
