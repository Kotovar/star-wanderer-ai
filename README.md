# 🚀 Star Wanderer AI

**Star Wanderer AI** — экспериментальная космическая пошаговая стратегия, где игрок управляет кораблём, исследует галактику, торгует, сражается и взаимодействует с процедурными событиями.

Проект создан и реализован на ~99% как эксперимент по оценке возможностей генеративных ИИ-моделей в разработке игровых систем. 

---

## 🌌 Game Overview

Игровой цикл включает:

* Исследование секторов галактики
* Пошаговые тактические бои
* Торговлю и выполнение заданий
* Добычу ресурсов
* Аномалии и случайные события
* Артефакты и древних боссов

Корабль состоит из модулей (реактор, щиты, сканер, оружие, бур и др.), которые можно тактически перемещать во время хода.

Экипаж разных рас и специализаций усиливает боевые, научные и инженерные возможности экспедиции.

---

## 🧠 AI Experiment

Проект реализован преимущественно с использованием генеративных моделей как инструмента разработки.

Использованные модели:

* **Claude** — начальная архитектура, базовые механики
* **GLM-5** — расширение игровых систем
* **Qwen-Coder** — основная разработка, рефакторинг
* **DeepSeek** — точечные улучшения и вспомогательный код

---

## 🛰️ Local Launch (example)

```bash
git clone https://github.com/Kotovar/star-wanderer-ai.git
cd star-wanderer-ai
npm install
npm run dev
```

Проверки (Node.js 24; для аудио нужны `ffmpeg` и `ffprobe`):

```bash
npm run type-check
npm run lint
npm run build
npm run check:all
```

`check:all` находит все `scripts/check-*.mjs`, запускает до четырёх
параллельно и выводит сводку с первой строкой каждой ошибки. Проверка
стартовых шаблонов выполняется в development и production, остальные —
в production. При падении любой проверки команда завершается с кодом 1.
В GitHub Actions эти проверки запускаются при push и pull request;
перед `check:all` выполняется сборка. Известные падения перечислены
в [плане улучшений](docs/IMPROVEMENT_PLAN.md), пункт 1.2: в частности,
три проверки ленивой загрузки ожидают статистику, которую текущая
сборка не создаёт.
