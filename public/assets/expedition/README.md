# Исходники кадров спрайт-листа экспедиции

Эти PNG — **исходники**, игра их не грузит. Она читает собранный лист
`public/assets/expedition_locations.webp`: 9 кадров по 560×561, порядок задан
`TILE_SPRITE_INDEX` в `src/game/components/ExpeditionMapCanvas.tsx`.

Здесь лежат только четыре кадра клеток необитаемых планет. Первые пять
(рынок, лаборатория, руины, инцидент, артефакт) существуют лишь внутри
собранного листа — отдельных исходников у них не сохранилось.

## Если добавляется новый кадр

1. Нарисовать PNG с альфой ровно 560×561, объект по центру по горизонтали,
   низ подставки примерно на 460-й строке — тогда объект встанет на общую
   линию с остальными.
2. Пересобрать лист так, чтобы **ширина делилась на число кадров нацело**.
   У прежнего листа шаг был 560.8 px, и содержимое кадров стояло не по центру
   (отступы гуляли от 5 до 190 px) — код компенсировал это вручную через
   `TILE_SPRITE_OFFSET`. Поправки сняты вместе с выравниванием листа,
   возвращать их не нужно: правильнее выровнять сам лист.
3. Дописать тип в `TILE_SPRITE_INDEX` и поднять
   `EXPEDITION_LOCATION_SPRITE_COUNT`.
4. `npm run check:expedition-tiles` проверит, что индексы покрывают лист без
   дыр и повторов, ширина делится нацело, а у каждого типа клетки есть кадр.

Кодировать в webp с `quality=95`: lossless даёт вдвое больший файл ради
разницы, которая не видна — иконка рисуется с уменьшением примерно в семь раз.
