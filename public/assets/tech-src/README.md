# Исходники иконок технологий

Эти PNG — **исходники**, игра их не грузит. Она читает собранный лист
`public/assets/tech.webp`: сетка 7 столбцов на 6 рядов, 1586×992.
Иконки лежат не по ровной сетке — у каждой свой прямоугольник в
`TECH_ICON_RECTS_IN_ORDER` (`src/game/components/TechIcon.tsx`).

Здесь лежит только `autonomous_systems`. У остальных 39 отдельных исходников
не сохранилось — они существуют лишь внутри листа.

## Как добавить иконку

1. Нарисовать PNG с альфой примерно 160×150, без подставки под объектом
   (иконки технологий, в отличие от иконок локаций экспедиции, ни на чём
   не стоят).
2. Найти свободную ячейку. Центры соседей: столбец 0 ≈ x110, шаг столбца
   ≈ 218 px; нижний ряд ≈ y900, шаг ряда ≈ 155 px.
3. Вклеить содержимое по альфа-границе, отцентровав в ячейке. Проверить,
   что место пустое, — иначе затрёт чужую иконку.
4. Дописать id в **конец** `TECH_ICON_ORDER` и прямоугольник в **конец**
   `TECH_ICON_RECTS_IN_ORDER`. Списки идут парой по индексу: вставка в
   середину сдвинет все последующие иконки, и заметить это можно очень
   нескоро. `TechIcon` бросает исключение, если длины разошлись.
5. `npm run check:research-panel`.

## Кодирование

Сохранять с `quality=85`: lossless раздувает лист до 1.4 МБ, а иконки всё
равно рисуются размером 24 px, то есть с уменьшением примерно в шесть раз.

Помнить, что **каждая пересборка листа — ещё одно поколение потерь** для
всех сорока иконок, а не только для новой. Если добавляется сразу несколько
кадров, лучше вклеить их за один проход.
